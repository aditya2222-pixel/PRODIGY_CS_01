# Caesar Cipher GUI

## Task 01 - Prodigy InfoTech Cyber Security Internship

A Python GUI application that implements the Caesar Cipher algorithm for encrypting and decrypting text.

## Features

- Encrypt text using the Caesar Cipher algorithm
- Decrypt encrypted text
- User-defined shift value
- Simple graphical user interface
- Supports uppercase and lowercase letters
- Preserves spaces, numbers, and special characters

## Technologies Used

- Python
- Tkinter

## How It Works

The Caesar Cipher is a substitution cipher that shifts each letter in the message by a specified number of positions in the alphabet.

For example, with a shift value of 3:

- Original: `Hello World`
- Encrypted: `Khoor Zruog`

The same shift value can be used to decrypt the message.

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python caesar_cipher_gui.py
```
